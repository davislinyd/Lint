What Lint doesLint 的特點

Lint lives in the menu bar and checks the English you write, wherever you write it.

Lint 住在選單列，在你寫字的任何地方檢查你的英文。

Works in any app在任何 App 裡都能用

Select text in Mail, Notes, a browser, Slack or any other app and press a shortcut. Browsers and Electron apps work too: in their rich-text fields Replace writes only the changed words, so mentions, links and formatting stay. When a field exposes no text, Lint copies it through the clipboard and puts your clipboard back. The bubble opens on the Space you are in, fullscreen apps included.

在郵件、備忘錄、瀏覽器、Slack 或任何 App 選取文字，按下快捷鍵就行。瀏覽器與 Electron App 也支援：在它們的富文字輸入框裡，取代只會改寫有變動的字，提及、連結與格式都會保留。輸入框讀不到文字時，Lint 會透過剪貼簿複製，再把你的剪貼簿還原。浮窗會出現在你正在使用的 Space，包含全螢幕 App。

Two ways to review兩種檢查方式

⌥⌘K shows a small bubble with the suggestion; ⌥⌘L opens a side-by-side panel with every change marked. Replace your text in place, edit the suggestion first, copy the result or ask for a rewrite. Lint starts preparing a suggestion as soon as you select text, so it is usually ready at once.

⌥⌘K 以小浮窗顯示建議；⌥⌘L 打開雙欄面板，標出每一處修改。可以直接取代原文、先修改建議再取代、複製結果，或要求重寫。你一選取文字，Lint 就開始準備建議，所以通常馬上就好。

Careful English editing細心的英文潤飾

Proofread & polish fixes grammar, wrong words and spelling, and tries to keep correct wording, names, numbers and your layout as they are. Pick a tone (Idiomatic, the default, which also rewrites correct English that a native speaker would not write, untangles a sentence put together wrong and keeps your voice; Preserve Tone; Formal, Casual or Concise; all but Preserve Tone also write Chinese or another language as English), use Translate to read English text in the translation language you choose (Traditional Chinese by default), or write a Custom prompt.

「文法校對與潤飾」修正文法、用錯的字與拼字，並盡量保留正確的用字、人名、數字與版面。可以選語氣（預設的「道地」：也改寫文法正確但母語者不會這樣說的英文、把組得不對的句子理順，並保留你的語氣；保留原語氣；正式、輕鬆或簡潔；除了保留原語氣，都會把中文或其他語言寫成英文），用「翻譯」把英文翻成你選的翻譯語言來閱讀（預設繁體中文），或寫「自訂 Prompt」。

Your text stays on your Mac文字留在你的 Mac 上

Lint's local AI (a bundled llama.cpp running Gemma 4 E4B) and Apple Intelligence both run on the device; the network is only used to download the model and to check GitHub for Lint updates. If you prefer, point Lint at an OpenAI-compatible endpoint such as Ollama or LM Studio; an API key, if it needs one, is kept in the Keychain.

Lint 的本機 AI（內建 llama.cpp 執行 Gemma 4 E4B）和 Apple Intelligence 都在這台 Mac 上執行，只有下載模型和到 GitHub 檢查 Lint 更新時需要網路。也可以改接 Ollama、LM Studio 等 OpenAI 相容端點；需要 API Key 的話，Key 存在鑰匙圈。

Memory and dreaming (optional)記憶與作夢（選用）

Turn on Memory and Lint writes down the mistakes you correct as short rules, stored only on your Mac, reminds the model of them from the next suggestion on, and forgets the ones that don’t come back while it dreams. Observation Mode also learns from the text you actually send. You can read and delete every memory. How memory and dreaming work

開啟記憶後，Lint 會把你修正過的錯誤記成簡短規則，只存在你的 Mac，下一次建議就開始提醒模型，沒有再出現的會在作夢時忘記。「觀察模式」還會從你實際送出的文字學習。每一條記憶都能查看與刪除。記憶與作夢怎麼運作

Other apps can use the model (optional)讓其他 app 使用模型（選用）

Turn on Other Apps and your own scripts, apps and local web pages can call Lint's local model through an OpenAI-compatible API on this Mac, with a key. Lint's own suggestions always come first. How it works

開啟「其他 app 使用」後，你自己的腳本、App 和本機網頁就能用金鑰，透過這台 Mac 上的 OpenAI 相容 API 呼叫 Lint 的本機模型。Lint 自己的建議永遠優先。怎麼運作

Made to fit you依你的習慣調整

Change both shortcuts, switch the interface to one of nine languages, and edit the instructions for each mode and tone.

兩組快捷鍵都能更改，介面可以切換成九種語言之一，每個模式與語氣的指示也都能修改。

Before you start開始之前

  • A Mac with Apple silicon, running macOS 14 Sonoma or later.
  • For Lint's own local AI: about 6.2 GB of free disk space (the default model is about 5.15 GB), and an internet connection for that one download.
  • Or, on macOS 26 or later with Apple Intelligence turned on, Lint can use Apple Intelligence instead, with nothing to download.
  • 搭載 Apple 晶片、執行 macOS 14 Sonoma 或更新版本的 Mac。
  • 使用 Lint 自己的本機 AI：約 6.2 GB 可用空間（預設模型約 5.15 GB），以及下載這一次所需的網路。
  • 或者，在 macOS 26 以上且已開啟 Apple Intelligence 的 Mac，Lint 可以改用 Apple Intelligence，不必下載。

Download下載

1

Download the DMG下載 DMG

Open the latest release on GitHub and click Lint-0.16.1-macOS-arm64.dmg under Assets. A newer release has a newer number in the name.

打開 GitHub 上的最新版本，在 Assets 下點 Lint-0.16.1-macOS-arm64.dmg。之後的版本檔名裡的版本號會不同。

The DMG is in your Downloads folder.

「下載項目」資料夾裡有這個 DMG。

Optional: to check the download, also get Lint-0.16.1-macOS-arm64.dmg.sha256, then run shasum -a 256 -c Lint-0.16.1-macOS-arm64.dmg.sha256 in Terminal, in the folder that holds both files. It prints OK.

選用：想確認下載無誤，可以一併下載 Lint-0.16.1-macOS-arm64.dmg.sha256，在放著這兩個檔案的資料夾打開「終端機」，執行 shasum -a 256 -c Lint-0.16.1-macOS-arm64.dmg.sha256，會印出 OK。

Install安裝

2

Drag Lint into Applications把 Lint 拖進「應用程式」

Double-click the DMG. In the window that opens, drag Lint onto the Applications folder, where the arrow points. Then eject the Lint disk (⏏ next to it in the Finder sidebar).

雙擊 DMG。在開啟的視窗裡，照箭頭把 Lint 拖到 Applications 資料夾上。接著退出 Lint 磁碟（Finder 側邊欄裡它旁邊的 ⏏）。

Lint is in your Applications folder.

「應用程式」資料夾裡有 Lint。

3

Open Lint for the first time第一次打開 Lint

Open Lint from Applications (or press ⌘Space and type “Lint”). macOS asks whether to open an app downloaded from the internet: click Open. Lint is signed with a Developer ID and notarized by Apple, so macOS asks only this once.

從「應用程式」打開 Lint（或按 ⌘空白鍵 輸入「Lint」）。macOS 會問你是否要打開從網路下載的 App：按「打開」（英文系統顯示為 Open）。Lint 以 Developer ID 簽署並通過 Apple 公證，所以只會問這一次。

Lint's icon (a pen nib with a check mark) appears in the menu bar, and the Set Up Local AI window opens.

選單列出現 Lint 的圖示（筆尖加一個勾），並打開「設定本機 AI」視窗。

Set up the AI設定 AI

Lint needs a model to write its suggestions. Pick the one that suits your Mac.

Lint 需要一個模型來產生建議。選一個適合你這台 Mac 的。

4

Choose an AI engine選擇 AI 引擎

The Welcome to Lint window lists what Lint needs: the local AI runtime (already inside Lint), an AI model, and Accessibility. At the bottom, pick one:

「歡迎使用 Lint」視窗會列出 Lint 需要的東西：本機 AI 執行環境（已內建）、AI 模型與輔助功能。在下方選一個：

  • Download AI Model (recommended): Lint downloads and installs everything it needs and runs Gemma 4 E4B on your Mac. It catches more mistakes. One download of about 5.15 GB.
  • Use Apple Intelligence Instead: uses the on-device model built into macOS, with no download. It mostly fixes typos and basic grammar. This button appears only when your Mac can use Apple Intelligence.
  • Later: closes the window. Until Lint is ready, opening Settings or pressing ⌥⌘K or ⌥⌘L brings this window back.
  • Use Another Model Source…: opens Settings, for example to use an OpenAI-compatible endpoint instead.
  • 「下載 AI 模型」（建議）：Lint 會幫你下載並安裝所有需要的元件，在你的 Mac 上執行 Gemma 4 E4B，能抓出較多錯誤。需要下載一次，約 5.15 GB。
  • 「改用 Apple Intelligence」：使用 macOS 內建的裝置端模型，不必下載，主要修正拼字與基本文法。只有這台 Mac 能使用 Apple Intelligence 時才會出現這個按鈕。
  • 「稍後」：先關閉視窗。在 Lint 能運作之前，打開設定或按 ⌥⌘K、⌥⌘L 都會回到這個視窗。
  • 「使用其他模型來源…」：打開設定，例如改用 OpenAI 相容端點。

If you chose Apple Intelligence, skip to Allow Accessibility.

如果你選了 Apple Intelligence，直接跳到「允許輔助功能」。

5

Download the model下載模型

After Download AI Model, Lint shows what it is about to download: the model, its size, the free space it needs, what your Mac has, and the license. Your text is never sent to a server; the network is only used for this download. Click Download and Install.

按下「下載 AI 模型」後，Lint 會先列出即將下載的內容：模型、大小、需要的可用空間、這台 Mac 目前的空間與授權。你的文字不會送到任何伺服器，只有這次下載需要網路。按「下載並安裝」。

A progress bar. At 100% Lint checks the file (SHA-256), installs it and starts the local AI. The first start can take a minute.

出現進度條。到 100% 後，Lint 會驗證檔案（SHA-256）、安裝並啟動本機 AI。第一次啟動可能要一分鐘左右。

Tip: you can cancel, lose the connection or even quit Lint. The part already downloaded is kept, and the download continues where it stopped.

提示：可以取消、斷線，甚至結束 Lint。已下載的部分會保留，再次下載時從中斷處繼續。

Allow Accessibility允許輔助功能

Lint reads the text you select and writes the suggestion back through macOS Accessibility.

Lint 透過 macOS 的「輔助功能」讀取你選取的文字，並把建議寫回去。

6

Let Lint read and replace text允許 Lint 讀取與取代文字

When the AI is ready, the window shows the last step. Click Allow Accessibility and follow macOS to System Settings, or click Open System Settings Manually.

AI 準備好之後，視窗會顯示最後一步。按「授權輔助功能」，依 macOS 的提示前往系統設定；或按「手動打開系統設定」。

In System Settings → Privacy & Security → Accessibility, turn on Lint. On macOS 27 this list is called Device Control and Data Access. If Lint is not in the list, click + and choose Lint in Applications.

在「系統設定 → 隱私權與安全性 → 輔助功能」打開 Lint。macOS 27 把這份列表改名為 Device Control and Data Access（英文介面名稱）。列表裡沒有 Lint 的話，按 ＋，在「應用程式」裡選 Lint。

Back in the Lint window, Accessibility says Enabled and you see All set. Click Done.

回到 Lint 視窗，輔助功能顯示「已啟用」，並出現「一切就緒」。按「完成」。

Without Accessibility Lint still works, but it falls back to copying and pasting through the clipboard.

沒有輔助功能權限時，Lint 仍然可以使用，但會改用剪貼簿複製貼上。

Use Lint開始使用

Lint works in any app where you can select text: Mail, Notes, browsers, Slack and more. It edits English, and its tones other than Preserve Tone write Chinese, other languages or mixed text as English; Translate helps you read English text in the translation language you choose.

只要能選取文字的 App 都能用 Lint：郵件、備忘錄、瀏覽器、Slack 等。Lint 修改英文，除了「保留原語氣」以外的語氣也會把中文、其他語言或中英夾雜的文字寫成英文；「翻譯」則把英文翻成你選的翻譯語言，幫你讀懂。

7

Quick check: ⌥⌘K快速檢查：⌥⌘K

Select some English text, or just put the cursor in a text field, and press ⌥⌘K. Lint starts preparing a suggestion as soon as you select text, so it usually appears at once.

選取一段英文，或只把游標放在輸入框裡，按 ⌥⌘K。Lint 在你選取文字時就開始準備建議，所以通常會立刻出現。

A bubble shows the suggestion, with a reference translation underneath (in your translation language, Traditional Chinese by default) to help you check the meaning. Its buttons are Replace ⏎, Edit E, Rewrite R and Close esc.

浮窗會顯示建議，下方附參考譯文（用你設定的翻譯語言，預設繁體中文），方便你核對意思。按鈕依序是「取代 ⏎」、「編輯 E」、「重寫 R」與「關閉 esc」。

To keep only part of it, press E and edit the suggestion right in the bubble. There ⏎ starts a new line and ⌘⏎ replaces your text with your version; esc ends the edit and keeps it, and a second esc closes the bubble. With Lint's local AI or Apple Intelligence, the reference translation follows your edit as you type. With Memory on, Lint learns from what you changed.

只想接受一部分時，按 E 直接在浮窗裡修改建議。編輯時 ⏎ 是換行，⌘⏎ 用你的版本取代原文；esc 結束編輯並保留修改，再按一次 esc 關閉浮窗。使用 Lint 本機 AI 或 Apple Intelligence 時，參考譯文會跟著你的修改更新。開啟記憶時，Lint 會從你改的地方學習。

When the text needs no changes, the bubble says so. After Preserve Tone, Rewrite R becomes Idiomatic R to try the Idiomatic tone instead.

文字不需要修改時，浮窗會直接告訴你；在「保留原語氣」下，「重寫 R」會變成「改用道地 R」，讓你改試「道地」語氣。

8

Side by side: ⌥⌘L並排比對：⌥⌘L

Select text and press ⌥⌘L, or press it with nothing selected to take the paragraph you are writing. The full panel shows your original on the left (you can edit it) and the result on the right, with the changes marked.

選取文字後按 ⌥⌘L；沒有選取時，會帶入你正在寫的那一段。全面板左邊是原文（可以直接修改），右邊是標出修改處的結果。

  • Mode: Proofread & polish, Translate, or Custom prompt.
  • Tone: Preserve Tone, Idiomatic (proofreading only, and its default until you pick another), Formal, Casual or Concise.
  • Replace Original ⌘⏎, Copy ⌥⌘C, Retry ⌥⌘⏎. Tick Edit to change the result before you use it.
  • Generate as you type: when you type or edit the original, the result follows once you pause. It is on by default for Automatic, Apple Intelligence and Lint's local AI, and is not offered for engines that charge per request.
  • 模式：文法校對與潤飾、翻譯，或自訂 Prompt。
  • 語氣：保留原語氣、「道地」（只有校對有，在你選別的語氣之前是預設）、正式、輕鬆或簡潔。
  • 覆蓋取代 ⌘⏎、複製 ⌥⌘C、重試 ⌥⌘⏎。勾選「編輯」可以先修改結果再使用。
  • 輸入時即時產生：輸入或修改原文時，停下來一下結果就會跟著更新。使用自動、Apple Intelligence 或 Lint 本機 AI 時預設開啟；按次計費的模型來源不提供。

Write it in Chinese when you know what you mean but not how to say it. Select Chinese or mixed text with Idiomatic, Formal, Casual or Concise, and Lint writes it the way a native English speaker would, always in English. For example, 「抱歉，這個需求我們這季排不進去，下季再評估看看。」 becomes “Sorry, we can't fit this request into this quarter. Let's reassess it next quarter.” In Formal, 「我覺得這個方案風險太高，建議我們先做小範圍測試，再決定要不要全面上線。」 becomes “I believe this proposal carries too much risk. I suggest we conduct a small-scale test first before deciding on a full-scale launch.” The reference translation under the suggestion shows what the English says. Read the result before you replace the original: the small local model sometimes rewords text that was already natural.

直接寫中文：知道想說什麼、卻不知道英文怎麼說的時候，選取中文或中英夾雜的文字並使用「道地」「正式」「輕鬆」或「簡潔」，Lint 會用英語母語者會說的方式寫出來，輸出一律是英文。例如「抱歉，這個需求我們這季排不進去，下季再評估看看。」會變成 “Sorry, we can't fit this request into this quarter. Let's reassess it next quarter.”；在「正式」下，「我覺得這個方案風險太高，建議我們先做小範圍測試，再決定要不要全面上線。」會變成 “I believe this proposal carries too much risk. I suggest we conduct a small-scale test first before deciding on a full-scale launch.”。建議下方的參考譯文會顯示這段英文在說什麼。取代原文之前請先看過結果：本機的小型模型有時會把本來就很道地的句子改寫。

Text mixed with English. When English is mixed with Chinese or another language in its own script (Japanese, Korean, Thai and so on), Settings → General decides whether it is written all in English (the default) or keeps that language and has only its English edited. A language in Latin letters mixed with English, such as Vietnamese or Indonesian, is always written in English. Preserve Tone always edits only the English.

夾雜英文的文字。中文或日文、韓文、泰文等有自己文字的語言夾雜英文時，要整段寫成英文（預設），還是保留那個語言、只改英文，可在設定 → 一般選擇；越南文、印尼文等用拉丁字母的語言夾英文時一律寫成英文。「保留原語氣」一律只改英文。

The menu bar menu選單列選單

Click Lint's icon, a pen nib with a check mark. The first row shows the local model's state: not loaded, loading, running, idle (its memory was released after a while without suggestions), restarting or failed; the dot on the icon shows the same. Open that row to switch to another model or to Apple Intelligence (a model that is not downloaded yet shows its size and asks first; its download progress then shows in that row, and it starts when it is in), or to start, stop, restart or recheck the local server. Below it are Improve Selected Text, the Mode and Tone, whether Accessibility is on, the CPU and memory that Lint and the AI model use (counted as Activity Monitor does and updated every second while the menu is open; while a local model is loaded, the size of its model file is listed too, since its weights are not counted in that memory), Set Up Local AI… (until the local AI is set up), Check for Updates…, the version, Diagnostic Log…, Settings… and Quit Lint. When a newer release is found, the menu also offers to download and install it.

點選單列上 Lint 的圖示（筆尖加一個勾）。第一行顯示本機模型的狀態：未載入、載入中、運作中、閒置中（一段時間沒要求建議後已釋放記憶體）、重啟中或失敗，圖示上的小圓點也會顯示同樣的狀態。展開這一行可以切換到其他模型或 Apple Intelligence（還沒下載的模型會先列出大小並詢問，同意後下載進度就顯示在這一行，下載完成後自動啟動），也可以啟動、停止、重新啟動或重新檢查本機服務。下面是「改善選取文字」、切換「模式」與「語氣」、輔助功能是否已開啟、Lint 與 AI 模型使用的 CPU 和記憶體（算法與活動監視器相同，選單開著時每秒更新；本機模型載入時還會列出模型檔大小，因為模型權重不算在這個記憶體裡）、「設定本機 AI…」（本機 AI 設定好之前才有）、「檢查更新…」、版本號、「診斷記錄…」，以及「設定…」與「結束 Lint」。找到較新的正式版時，選單也會提供下載並安裝。

Settings設定

Open Settings… from the menu bar menu.

從選單列選單打開「設定…」。

General一般

Accessibility status, Check Behavior (the Check button, watching while you type, the “Ready” chip), Shortcuts (change ⌥⌘L and ⌥⌘K), Language (the interface language, one of nine or the system's, after a restart; and the translation language, Traditional Chinese by default) and Updates (ask before installing, install automatically or only check, every launch, day, week or month).

輔助功能狀態、「檢查行為」（「檢查」按鈕、打字時即時監看、「已就緒」浮標）、「快捷鍵」（可更改 ⌥⌘L 與 ⌥⌘K）、「語言」（介面語言可選九種語言或跟隨系統，重新啟動後套用；翻譯語言預設繁體中文），以及「更新」（手動更新、自動更新或只檢查；每次啟動、每天、每週或每月）。

Model模型

Under Model Source, pick where suggestions come from: Automatic, Apple Intelligence, Local llama.cpp (managed by Lint), or an OpenAI-compatible endpoint (Ollama, LM Studio); an API key, if the endpoint needs one, is kept in the Keychain. 打開「設定… → 記憶」，開啟「啟用記憶」。記憶數從 0 開始，會隨著你使用 Lint 增加。下方還可以開啟「觀察模式」（見「觀察模式」）。

How a memory is formed記憶怎麼形成

  • A memory comes from what you do with a suggestion. Editing the result before you replace your text counts the most, because those are your own words; replacing counts less, copying a little, and asking for a rewrite records nothing.
  • A new memory is used from the next suggestion on: it is short-term. If its pattern comes back within 7 days, or the model applies it and you accept that, it becomes long-term; if not, it is forgotten while dreaming. A change the model made that depends on its sentence, such as “tickets” for “ticket”, is used only once it comes back. Undoing what a memory asks for counts twice as much against it, and forgets it at once unless it is well established.
  • When you write, Lint adds the few memories that fit your text, at most five short lines, to the end of the prompt. With Lint's local AI or Apple Intelligence they never leave your Mac; with a cloud provider they are sent along with your text.
  • 記憶來自你怎麼處理建議。在取代前先修改結果最有份量，因為那是你自己的用字；直接取代次之，複製只算一點，要求重寫則不會記下任何東西。
  • 新記下的記憶從下一次建議就開始使用，這是短期記憶。7 天內同樣的樣式又出現，或模型照提醒改了而你接受，它就轉成長期記憶；沒有的話就在作夢時忘記。模型改的、要看句子而定的修正（例如「tickets」改成「ticket」）要再出現一次才會使用。你若推翻某條記憶要求的改法，扣分是加分的兩倍，而且除非它已經很穩固，否則會立刻忘記。
  • 你寫作時，Lint 只把符合這段文字的少數記憶（最多五行短句）加在 prompt 結尾。使用 Lint 本機 AI 或 Apple Intelligence 時，它們不會離開你的 Mac；使用雲端服務時，會隨你的文字一起送出。

What is kept會記下什麼

  • Everything stays on your Mac, in ~/Library/Application Support/Lint/LintLearning.sqlite, readable only by you. The settings page calls this Memory; the file name stays LintLearning.sqlite.
  • Only abstracted rules are kept: a word, a short phrase or a template sentence, never the text around it. Numbers, addresses, paths, acronyms and capitalized names are left out.
  • Lint cannot recognize Chinese names or names typed in lowercase, so a name you corrected may still end up in a memory. You can find and delete it under Manage Memories….
  • What you did with a suggestion is logged as keyed hashes, not text; the key is in your Keychain.
  • 全部只存在你的 Mac：~/Library/Application Support/Lint/LintLearning.sqlite，僅你本人可讀。設定頁現在叫記憶，檔名仍是 LintLearning.sqlite。
  • 只保存抽象後的規則：一個字、一小段詞組或模板句，不保存周圍的文字。數字、網址、路徑、縮寫與大寫開頭的人名不會被記下。
  • Lint 認不出中文人名或全小寫的英文名，被你修正過的名字仍可能進入記憶；可以在「管理記憶…」找到並刪除。
  • 你對建議做了什麼，只以帶金鑰的雜湊記錄，不含文字；金鑰放在你的鑰匙圈。

Observation mode觀察模式

  • Optional and off by default; it needs Memory on. After a suggestion, Lint keeps reading that field until the text is sent (the field empties), the field goes away or 10 minutes pass without a change, and notes whether the suggestion was used, looked at and left, or never opened. Only proofreading is followed. Password fields and password managers are never read.
  • The text is only compared in memory, never written to disk. The database gets a count per app that fades with time and, for a suggestion you looked at and did not use, keyed hashes.
  • From what you sent, Lint learns what to leave alone. A word you put back after Replace becomes a memory to keep it, used from the next suggestion on. A change you looked at and sent without becomes one the second time it happens, under Preserve Tone and Idiomatic only, since the other tones rewrite on purpose.
  • It also learns your style: contractions or full forms you keep, no period at the end of a message, a lowercase start. One you keep in at least 80% of 8 or more recent cases is written into a memory of your style while dreaming, which you can edit or delete like any other.
  • Dreaming also adjusts Lint per app. In an app where 30 recent suggestions went unused, nothing is prepared on its own any more; ⌥⌘K still checks, and using it there ends the quiet. In an app where at least 80% of the suggestions you used lately were in one tone, automatic suggestions use that tone until you pick one by hand. Settings → Memory lists each adjustment with a Remove button and shows the Recent adoption rate.
  • 選用功能，預設關閉，需要先啟用記憶。給過建議後，Lint 會繼續讀取那個輸入框，直到文字送出（輸入框清空）、輸入框消失，或 10 分鐘沒有變動，並記下建議是被採用、看過沒用，還是從未打開。只追蹤校對的建議。密碼欄位與密碼管理 App 一律不讀。
  • 文字只在記憶體裡比對，不會寫入磁碟。資料庫只會多出各 App 會隨時間淡出的次數，以及「看過但沒採用」的建議的帶金鑰雜湊。
  • Lint 會從你送出的文字學到哪些地方不要改。取代後你又改回原字，就記成「保留這個字」的記憶，下一次建議就開始使用。你看過、但送出時沒有採用的改動，第二次發生時才會成為記憶，而且只限「保留原語氣」與「道地」，因為其他語氣本來就會改寫。
  • 它也會學你的寫法：保留縮寫或完整寫法、訊息結尾不加句點、開頭用小寫。近期至少 8 次、其中 80% 以上都保留的寫法，會在作夢時寫成一條「你的寫法」記憶，和其他記憶一樣可以修改或刪除。
  • 作夢也會依 App 調整 Lint。某個 App 裡近期 30 次建議都沒被採用，Lint 就不再自動為它準備建議；⌥⌘K 仍可檢查，在那裡用一次就會恢復。某個 App 裡近期採用的建議至少 80% 是同一種語氣，那裡的自動建議就改用那種語氣，直到你手動選語氣。「設定 → 記憶」會列出每項調整並附「移除」按鈕，也會顯示「近期採用率」。

Dreaming作夢

Dreaming writes down which memories proved themselves and which are forgotten, and erases traces that have faded. A forgotten memory is no longer used. Only a trace is kept, so that Lint recognizes the pattern, and keeps it at once, if it comes back. A long-term memory that stops showing up fades: after a month without it, its evidence halves every three months (every six months for a general rule, every year for a core memory), and below half of where it started it is forgotten. A trace that has faded away is erased for good, roughly three to eleven months after the pattern was last seen. Pinned and disabled memories don't fade, neither they nor memories you reworded are ever erased, and Enable brings a forgotten memory back.

When several memories of one kind pile up, a dream sums them up in one general rule. For now it handles one kind: a preposition you keep deleting after different verbs, such as “discuss about” and “mention about”. The rule is worded from a fixed template, so it never contains a word you wrote. The memories behind it are kept and come back if the rule fades, is disabled or is deleted; pinned, disabled and hand-edited memories are never combined, and a rule you delete is not made again. A rule that keeps proving itself for weeks becomes a core memory.

Dreaming runs only on your Mac, when you are not waiting for a suggestion: at least once a day while you use Lint (a minute after it starts, or after your first feedback of the day), after enough new memories, or when you click Dream Now, which then shows how many memories it remembered, forgot and erased.

作夢會記下哪些記憶證明有用、哪些要忘記，並刪除已經淡掉的痕跡。忘記的記憶不再使用，只留下痕跡，讓 Lint 在同樣的樣式又出現時認出來並直接留下。長期記憶不再出現就會淡出：超過一個月沒出現後，證據每三個月減半（一般規則每六個月、核心記憶每一年），低於起始的一半就忘記。淡掉的痕跡會被永久刪除，大約是最後一次出現後三到十一個月。已釘選與已停用的記憶不會淡出，它們和你改寫過的記憶都不會被刪除；按「啟用」可以把忘記的記憶找回來。

同一類的記憶累積多條時，作夢會把它們歸納成一條一般規則。目前只處理一類：你在不同動詞後反覆刪掉的介系詞，例如「discuss about」與「mention about」。規則由固定模板寫成，不會含有任何你寫過的字。被歸納的記憶都會保留，規則淡出、停用或被刪除後就會恢復；已釘選、已停用與你手動改寫過的記憶不會被歸納，你刪掉的規則也不會再被產生。持續數週都證明有用的規則會升為核心記憶。

作夢只在你的 Mac 上進行，並等到你不在等建議時才開始：使用 Lint 期間至少每天一次（啟動一分鐘後，或當天第一次回饋後）、累積足夠的新記憶之後，或按下「現在作夢」，完成後會顯示記住、忘記與刪除了幾條。

Manage your memories管理記憶

Manage Memories… lists every memory. You can edit, pin, disable, enable or delete each one, and see whether it is short-term, long-term or forgotten (forgotten ones are listed when you turn on Show forgotten memories), whether it is specific, general or core, and which memories a rule came from. Clear All Memories… deletes every memory but keeps the feedback log; Reset Memory Database… deletes the memories and the log, and cannot be undone.

「管理記憶…」會列出每一條記憶。每一條都可以編輯、釘選、停用、啟用或刪除，也能看到它是短期、長期還是已忘記（打開「顯示已忘記的記憶」才會列出已忘記的）、是具體、一般還是核心記憶，以及一般規則由哪些記憶歸納而來。「清除所有記憶…」會刪除所有記憶但保留回饋紀錄；「重設記憶資料庫…」會刪除記憶與回饋紀錄，無法復原。

在模型來源是「本機 llama.cpp」的「設定… → 模型」，到「其他 app 使用」打開「讓其他 app 使用本機模型」。拷貝「網址」（http://127.0.0.1:8001/v1，API 埠可以改）和一把金鑰：可以用「新增 API Key」取個名稱，給每個 App 或網頁各自一把，或使用「預設」那把（「顯示」、「拷貝」）。同一區也有可以直接拷貝的範例。

金鑰：每把都請當作密碼保管。「註銷…」會立刻停用其中一把，只有用它的 App 會失去權限（已經在進行的請求會跑完）。關掉這個設定會立刻關閉埠，不必重新啟動任何東西。

Call it from an app or a script從 App 或腳本呼叫

Send the key as Authorization: Bearer <key> or X-Api-Key: <key>. The routes are POST /v1/chat/completions, POST /v1/completions, GET /v1/models and GET /health; streaming works. Any OpenAI client library works with the URL as its base URL. In these examples, put your key in LINT_API_KEY first.

金鑰以 Authorization: Bearer <金鑰> 或 X-Api-Key: <金鑰> 送出。可用的路徑是 POST /v1/chat/completions、POST /v1/completions、GET /v1/models 與 GET /health，也支援串流。任何 OpenAI 用戶端程式庫，把上面的網址設成 base URL 就能用。下面的範例請先把金鑰放進 LINT_API_KEY。

curl http://127.0.0.1:8001/v1/chat/completions \
  -H "Authorization: Bearer $LINT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello"}]}'
import os
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8001/v1", api_key=os.environ["LINT_API_KEY"])
reply = client.chat.completions.create(
    model="gemma",  # any name: Lint runs one model
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.choices[0].message.content)

Using an AI agent such as Claude Code, Codex or Cursor? Give it this prompt: it tells the agent how to call the API, wait its turn and handle errors.

用 Claude Code、Codex、Cursor 等 AI agent 的話，把這份 prompt（英文）交給它：裡面說明怎麼呼叫 API、怎麼等候輪到它，以及怎麼處理錯誤。

Use it from a web page從網頁使用

  • A page you made can use the API only if its address is in Allowed websites, and it needs a key too. By default the list holds pages served from this Mac: http://localhost, http://127.0.0.1 and https://localhost, at any port.
  • For a page on your local network or your own domain, add its http or https address, such as http://192.168.1.5:3000 or https://tool.example.com; https://*.example.com covers every subdomain of example.com. Restore Defaults takes them out again. Other websites and local files (file://) cannot get in.
  • Allow browser extensions to use the API (off) lets extensions in Chrome, Brave, Edge, Firefox and Safari in, with a key. Extensions can see the pages you browse, so give a key only to ones you trust.
  • Browsers differ: Chrome and Brave let an allowed https website in, and Chrome an http page on the local network. Safari does not let any https page connect to an http address on this Mac, so in Safari no https page can use it.
  • 自製網頁的網址必須在「允許的網站」裡才能使用 API，而且一樣需要金鑰。清單預設只有這台 Mac 上的網頁：http://localhost、http://127.0.0.1 與 https://localhost，任何埠都可以。
  • 架在區域網路或自己網域上的網頁，可以加入它的 http 或 https 網址，例如 http://192.168.1.5:3000 或 https://tool.example.com；https://*.example.com 代表 example.com 底下的所有子網域。「恢復預設」會再把它們移除。其他網站與本機檔案（file://）都不能用。
  • 「允許瀏覽器擴充功能使用 API」（預設關閉）會放行 Chrome、Brave、Edge、Firefox 與 Safari 的擴充功能，一樣需要金鑰。擴充功能看得到你瀏覽的網頁，只把金鑰給你信任的擴充功能。
  • 瀏覽器之間有差異：Chrome 與 Brave 會讓允許的 https 網站使用，Chrome 也讓區域網路上的 http 網頁使用；Safari 不讓任何 https 網頁連到這台 Mac 的 http 位址，所以在 Safari 上 https 網頁都無法使用。

Lint comes firstLint 永遠優先

  • The model answers one request at a time. When Lint needs it for a suggestion, a translation or to warm up while you type, the other app's request is interrupted at once.
  • If that request had not received anything yet, Lint sends it again when it is done, so the app only waits longer. A streamed answer that was already under way ends with an error (preempted_by_lint).
  • While Lint uses the model, for 3 seconds after, and while you type, other requests wait: at most 8 of them, each for up to 2 minutes. Beyond that they get 503 with Retry-After.
  • On a test Mac, with another app generating a long answer, a suggestion still came in 0.4–1.3 seconds.
  • 模型一次只處理一個請求。Lint 需要它來給建議、翻譯，或在你打字時暖機，其他 app 的請求會立刻被中斷。
  • 如果那個請求還沒收到任何回應，Lint 用完後會自動重送，那個 App 只會覺得比較慢。已經開始串流的回答則以錯誤（preempted_by_lint）結束。
  • Lint 使用模型時、之後 3 秒內，以及你打字時，其他請求會等候：最多 8 個、每個最多 2 分鐘，超過就回 503 並附 Retry-After。
  • 實測在其他 app 正在產生長回答時，建議仍在 0.4–1.3 秒內出來。

What stays protected哪些仍受保護

  • The port listens on 127.0.0.1 only, so other computers cannot reach it, and a request must name 127.0.0.1 or localhost.
  • Lint's own model server (port 8000) answers only Lint: it takes a key Lint makes each time it starts, and web pages cannot read its answers. Only the routes above are passed on.
  • The diagnostic log records counts, status codes and times for these requests, never their text, the key or the site that sent them.
  • Scripts that called http://127.0.0.1:8000 directly before Lint 0.16.0 now get 401: use the API port and its key instead.
  • 這個埠只監聽 127.0.0.1，其他電腦連不到；請求也必須指名 127.0.0.1 或 localhost。
  • Lint 自己的模型服務（8000 埠）只回應 Lint：它帶著 Lint 每次開啟時產生的金鑰，網頁也讀不到它的回應。只有上面那幾個路徑會被轉送。
  • 診斷記錄對這些請求只記次數、狀態碼與時間，不記內容、金鑰，也不記是哪個網站送來的。
  • Lint 0.16.0 之前直接呼叫 http://127.0.0.1:8000 的腳本，現在會收到 401：請改用 API 埠與它的金鑰。

Troubleshooting疑難排解

Lint cannot read or replace textLint 讀不到或取代不了文字

Check Settings → General → Accessibility. After an update macOS may treat Lint as a new app: in System Settings → Privacy & Security → Accessibility, remove the old Lint entries, click + and add /Applications/Lint.app again.

檢查「設定 → 一般 → 輔助功能」。更新後 macOS 可能把 Lint 當成新的 App：到「系統設定 → 隱私權與安全性 → 輔助功能」刪除舊的 Lint 項目，按 ＋ 重新加入 /Applications/Lint.app。

Replace says “Nothing was written.”取代時顯示「沒有寫入。」

Lint only writes over the exact text it checked. If that text has changed, moved or is no longer selected, Lint leaves the field as it is. Select the text again and check it once more.

Lint 只會寫在它檢查過的那段原文上。原文如果改過、移動了，或已經不在選取範圍內，Lint 就不動輸入框。重新選取文字，再檢查一次。

Replace says it could not confirm the text was written取代時顯示「無法確認已寫入」

The field could be read before the replace but did not show the new text afterwards. Look at the field, and undo with ⌘Z if it is wrong.

取代前讀得到輸入框，取代後卻看不到新文字。請看一下輸入框，不對的話按 ⌘Z 還原。

macOS asks to let Lint control “System Events”macOS 詢問是否允許 Lint 控制「系統事件」

Allow it. Lint only uses it to bring your previous app back to the front before it replaces text, which makes Replace reliable in browsers and Electron apps.

請允許。Lint 只用它在取代文字前，把你原本使用的 App 帶回最前面，這樣在瀏覽器與 Electron App 裡取代才穩定。

The first suggestion takes a while第一個建議要等一下

The model is loading. On a Mac that is short of memory this can take minutes; Lint waits up to 10 minutes. After 5 minutes without a suggestion the model leaves memory, and the next request loads it again in a few seconds.

模型正在載入。在記憶體吃緊的 Mac 上可能要幾分鐘，Lint 最多等 10 分鐘。5 分鐘沒有要求建議時，模型會先釋放記憶體，下次要求時幾秒內重新載入。

The download stopped下載中斷了

Choose Set Up Local AI… in the menu bar menu and download again: it continues where it stopped. A file that fails its check is deleted and never used.

在選單列選單點「設定本機 AI…」再下載一次，會從中斷處繼續。驗證失敗的檔案會被刪除，絕不會使用。

Lint's icon is not in the menu bar選單列上找不到 Lint 的圖示

When the menu bar is full, macOS hides some icons. Close a few menu bar apps, check System Settings → Menu Bar on newer macOS, or look in your menu bar manager (such as Bartender or Ice). Lint's shortcuts work either way.

選單列太滿時，macOS 會隱藏部分圖示。可以關掉幾個選單列 App；在較新的 macOS 上檢查「系統設定 → 選單列」；或到你的選單列管理工具（例如 Bartender、Ice）裡找。不管圖示有沒有顯示，Lint 的快捷鍵都能用。

Not enough disk space磁碟空間不足

Before downloading, Lint checks for about 1.2 times what is still missing and tells you how much it needs and how much your Mac has.

下載前，Lint 會檢查是否有「還缺的部分 ×1.2」的空間，並告訴你需要多少、這台 Mac 有多少。

A new version is found but not installed找到新版卻沒有安裝

With Ask before installing (the default), choose Download and Install in Settings → General → Updates or in the menu bar menu. Lint only replaces a copy in /Applications or ~/Applications that is signed with Lint's Developer ID; otherwise it offers Open Release Page, where you can download the DMG yourself.

在「手動更新」（預設）下，到「設定 → 一般 → 更新」或選單列選單按「下載並安裝」。Lint 只會取代放在 /Applications 或 ~/Applications、並以 Lint 的 Developer ID 簽署的那一份；其他情況會提供「打開釋出頁面」，讓你自己下載 DMG。

Something else is wrong其他異常

Choose Diagnostic Log… in the menu bar menu (or Settings → Diagnostics) to see what Lint did and how it went: captures, replaces, model requests, the local server and errors. Copy adds the Lint version and your Mac's details, ready to paste into a GitHub issue. The log never contains your text; it stays on your Mac and is capped at about 2 MB.

在選單列選單點「診斷記錄…」（或「設定 → 診斷」），可以看到 Lint 做了什麼、結果如何：擷取、取代、模型請求、本機伺服器與錯誤。「拷貝」會附上 Lint 版本與這台 Mac 的資訊，可以直接貼到 GitHub issue。記錄不含你的文字，只存在你的 Mac，最多約 2 MB。
