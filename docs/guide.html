Install and use Lint安裝與使用 Lint

Step by step, from the download to your first suggestion. Each step says what you should see before you go on. 從下載到第一個建議，一步一步來。每一步都會告訴你，繼續之前應該看到什麼。

Before you start開始之前

  • A Mac with Apple silicon, running macOS 14 Sonoma or later.
  • For Lint's own local AI: about 6.2 GB of free disk space (the default model is about 5.15 GB), and an internet connection for that one download.
  • Or, on macOS 26 or later with Apple Intelligence turned on, Lint can use Apple Intelligence instead, with nothing to download.
  • 搭載 Apple 晶片、執行 macOS 14 Sonoma 或更新版本的 Mac。
  • 使用 Lint 自己的本機 AI：約 6.2 GB 可用空間（預設模型約 5.15 GB），以及下載這一次所需的網路。
  • 或者，在 macOS 26 以上且已開啟 Apple Intelligence 的 Mac，Lint 可以改用 Apple Intelligence，不必下載。

Download下載

1

Download the DMG下載 DMG

Open the latest release on GitHub and click Lint-0.3.4-macOS-arm64.dmg under Assets. A newer release has a newer number in the name.

打開 GitHub 上的最新版本，在 Assets 下點 Lint-0.3.4-macOS-arm64.dmg。之後的版本檔名裡的版本號會不同。

The DMG is in your Downloads folder.

「下載項目」資料夾裡有這個 DMG。

Optional: to check the download, also get Lint-0.3.4-macOS-arm64.dmg.sha256, then run shasum -a 256 -c Lint-0.3.4-macOS-arm64.dmg.sha256 in Terminal, in the folder that holds both files. It prints OK.

選用：想確認下載無誤，可以一併下載 Lint-0.3.4-macOS-arm64.dmg.sha256，在放著這兩個檔案的資料夾打開「終端機」，執行 shasum -a 256 -c Lint-0.3.4-macOS-arm64.dmg.sha256，會印出 OK。

Install安裝

2

Drag Lint into Applications把 Lint 拖進「應用程式」

Double-click the DMG. In the window that opens, drag Lint onto the Applications folder. Then eject the Lint disk (⏏ next to it in the Finder sidebar).

雙擊 DMG。在開啟的視窗裡，把 Lint 拖到 Applications 資料夾上。接著退出 Lint 磁碟（Finder 側邊欄裡它旁邊的 ⏏）。

Lint is in your Applications folder.

「應用程式」資料夾裡有 Lint。

3

Open Lint for the first time第一次打開 Lint

Open Lint from Applications (or press ⌘Space and type “Lint”). macOS asks whether to open an app downloaded from the internet: click Open. Lint is signed with a Developer ID and notarized by Apple, so macOS asks only this once.

從「應用程式」打開 Lint（或按 ⌘空白鍵 輸入「Lint」）。macOS 會問你是否要打開從網路下載的 App：按「打開」（英文系統顯示為 Open）。Lint 以 Developer ID 簽署並通過 Apple 公證，所以只會問這一次。

A pencil icon appears in the menu bar, and the Set Up Local AI window opens.

選單列出現鉛筆圖示，並打開「設定本機 AI」視窗。

Set up the AI設定 AI

Lint needs a model to write its suggestions. Pick the one that suits your Mac.

Lint 需要一個模型來產生建議。選一個適合你這台 Mac 的。

4

Choose an AI engine選擇 AI 引擎

The Welcome to Lint window lists what Lint needs: the local AI runtime (already inside Lint), an AI model, and Accessibility. At the bottom, pick one:

「歡迎使用 Lint」視窗會列出 Lint 需要的東西：本機 AI 執行環境（已內建）、AI 模型與輔助功能。在下方選一個：

  • Set Up Local AI (recommended): Lint runs Gemma 4 E4B on your Mac. It catches more mistakes. One download of about 5.15 GB.
  • Use Apple Intelligence Instead: uses the on-device model built into macOS, with no download. It mostly fixes typos and basic grammar. This button appears only when your Mac can use Apple Intelligence.
  • Later: closes the window. You can open it again from the menu bar with Set Up Local AI….
  • 「設定本機 AI」（建議）：Lint 在你的 Mac 上執行 Gemma 4 E4B，能抓出較多錯誤。需要下載一次，約 5.15 GB。
  • 「改用 Apple Intelligence」：使用 macOS 內建的裝置端模型，不必下載，主要修正拼字與基本文法。只有這台 Mac 能使用 Apple Intelligence 時才會出現這個按鈕。
  • 「稍後」：先關閉視窗。之後可從選單列的「設定本機 AI…」再打開。

If you chose Apple Intelligence, skip to Allow Accessibility.

如果你選了 Apple Intelligence，直接跳到「允許輔助功能」。

5

Download the model下載模型

After Set Up Local AI, Lint shows what it is about to download: the model, its size, the free space it needs, what your Mac has, and the license. Your text is never sent to a server; the network is only used for this download. Click Download and Install.

按下「設定本機 AI」後，Lint 會先列出即將下載的內容：模型、大小、需要的可用空間、這台 Mac 目前的空間與授權。你的文字不會送到任何伺服器，只有這次下載需要網路。按「下載並安裝」。

A progress bar. At 100% Lint checks the file (SHA-256), installs it and starts the local AI. The first start can take a minute.

出現進度條。到 100% 後，Lint 會驗證檔案（SHA-256）、安裝並啟動本機 AI。第一次啟動可能要一分鐘左右。

Tip: you can cancel, lose the connection or even quit Lint. The part already downloaded is kept, and the download continues where it stopped.

提示：可以取消、斷線，甚至結束 Lint。已下載的部分會保留，再次下載時從中斷處繼續。

Allow Accessibility允許輔助功能

Lint reads the text you select and writes the suggestion back through macOS Accessibility.

Lint 透過 macOS 的「輔助功能」讀取你選取的文字，並把建議寫回去。

6

Let Lint read and replace text允許 Lint 讀取與取代文字

When the AI is ready, the window shows the last step. Click Allow Accessibility and follow macOS to System Settings, or click Open System Settings Manually.

AI 準備好之後，視窗會顯示最後一步。按「授權輔助功能」，依 macOS 的提示前往系統設定；或按「手動打開系統設定」。

In System Settings → Privacy & Security → Accessibility, turn on Lint. On macOS 27 this list is called Device Control and Data Access. If Lint is not in the list, click + and choose Lint in Applications.

在「系統設定 → 隱私權與安全性 → 輔助功能」打開 Lint。macOS 27 把這份列表改名為 Device Control and Data Access（英文介面名稱）。列表裡沒有 Lint 的話，按 ＋，在「應用程式」裡選 Lint。

Back in the Lint window, Accessibility says Enabled and you see All set. Click Done.

回到 Lint 視窗，輔助功能顯示「已啟用」，並出現「一切就緒」。按「完成」。

Without Accessibility Lint still works, but it falls back to copying and pasting through the clipboard.

沒有輔助功能權限時，Lint 仍然可以使用，但會改用剪貼簿複製貼上。

Use Lint開始使用

Lint works in any app where you can select text: Mail, Notes, browsers, Slack and more. It edits English; Translate to Chinese helps you read English text in Chinese.

只要能選取文字的 App 都能用 Lint：郵件、備忘錄、瀏覽器、Slack 等。Lint 修改英文；「翻譯成中文」則幫你用中文讀懂英文。

7

Quick check: ⌥⌘K快速檢查：⌥⌘K

Select some English text, or just put the cursor in a text field, and press ⌥⌘K. Lint starts preparing a suggestion as soon as you select text, so it usually appears at once.

選取一段英文，或只把游標放在輸入框裡，按 ⌥⌘K。Lint 在你選取文字時就開始準備建議，所以通常會立刻出現。

A bubble shows the suggestion, with a Chinese translation underneath to help you check the meaning. Press ⏎ to replace your text, R to rewrite, esc to close, or click Edit in Full Panel.

浮窗會顯示建議，下方附中文翻譯，方便你核對意思。按 ⏎ 取代原文、R 重寫、esc 關閉，或點「在全面板編輯」。

8

Side by side: ⌥⌘L並排比對：⌥⌘L

Select text and press ⌥⌘L. The full panel shows your original on the left (you can edit it) and the result on the right, with the changes marked.

選取文字後按 ⌥⌘L。全面板左邊是原文（可以直接修改），右邊是標出修改處的結果。

  • Mode: Proofread & polish, Translate to Chinese, or Custom prompt.
  • Tone: Preserve Tone, Formal, Concise or Professional.
  • Replace Original ⌘⏎, Copy ⌥⌘C, Retry ⌥⌘⏎. Tick Edit to change the result before you use it.
  • 模式：文法校對與潤飾、翻譯成中文，或自訂 Prompt。
  • 語氣：保留原語氣、正式、簡潔或專業。
  • 覆蓋取代 ⌘⏎、複製 ⌥⌘C、重試 ⌥⌘⏎。勾選「編輯」可以先修改結果再使用。
9

The menu bar menu選單列選單

Click the pencil icon for Improve Selected Text, the Mode and Tone, whether Accessibility is on, Settings… and Quit Lint.

點選單列的鉛筆圖示，可以使用「改善選取文字」、切換「模式」與「語氣」、查看輔助功能是否已開啟，以及「設定…」與「結束 Lint」。

Settings設定

Open Settings… from the menu bar menu.

從選單列選單打開「設定…」。

10

General一般

Accessibility status, Check Behavior (the Check button, watching while you type, the “Ready” chip), Shortcuts (change ⌥⌘L and ⌥⌘K) and the Interface language (English or 繁體中文, after a restart).

輔助功能狀態、「檢查行為」（「檢查」按鈕、打字時即時監看、「已就緒」浮標）、「快捷鍵」（可更改 ⌥⌘L 與 ⌥⌘K）與「介面語言」（English 或繁體中文，重新啟動後套用）。

11

Model模型

Under Model Source, pick where suggestions come from: Automatic, Apple Intelligence, Local llama.cpp (managed by Lint), an OpenAI-compatible endpoint (Ollama, LM Studio), or OpenAI, Anthropic or Google Gemini with your own API key, which is kept in the Keychain. For the local AI you can pick the model (Gemma 4 E4B is recommended; Qwen3 4B and Gemma 4 12B are optional), start or stop the server, and remove a model.

在「模型來源」選擇建議的來源：自動、Apple Intelligence、本機 llama.cpp（由 Lint 管理）、OpenAI 相容端點（Ollama、LM Studio），或用你自己的 API Key 連 OpenAI、Anthropic、Google Gemini（Key 存在鑰匙圈）。使用本機 AI 時，可以選模型（建議 Gemma 4 E4B，也可以改用 Qwen3 4B 或 Gemma 4 12B）、啟動或停止服務，以及移除模型。

Memory: Gemma 4 12B needs much more memory. On a 16 GB Mac it can make the system very slow.

記憶體：Gemma 4 12B 需要多很多記憶體，在 16 GB 的 Mac 上可能讓系統變得非常慢。

12

Prompts and Learning提示詞與學習

Prompts: change the instructions for each mode and tone, or go back to the built-in ones.

提示詞：可以分別修改每個模式與語氣的指示，也能恢復內建預設。

Learning (optional, off by default): Lint remembers writing habits you keep correcting, as short rules kept only on your Mac. You can read, pin, disable or delete every memory under Manage Memories….

學習（選用，預設關閉）：Lint 會把你反覆修正的寫作習慣記成簡短規則，只存在你的 Mac 上。每一條記憶都可以在「管理記憶…」查看、釘選、停用或刪除。

Troubleshooting疑難排解

Lint cannot read or replace textLint 讀不到或取代不了文字

Check Settings → General → Accessibility. After an update macOS may treat Lint as a new app: in System Settings → Privacy & Security → Accessibility, remove the old Lint entries, click + and add /Applications/Lint.app again.

檢查「設定 → 一般 → 輔助功能」。更新後 macOS 可能把 Lint 當成新的 App：到「系統設定 → 隱私權與安全性 → 輔助功能」刪除舊的 Lint 項目，按 ＋ 重新加入 /Applications/Lint.app。

macOS asks to let Lint control “System Events”macOS 詢問是否允許 Lint 控制「系統事件」

Allow it. Lint only uses it to bring your previous app back to the front before it replaces text, which makes Replace reliable in browsers and Electron apps.

請允許。Lint 只用它在取代文字前，把你原本使用的 App 帶回最前面，這樣在瀏覽器與 Electron App 裡取代才穩定。

The first suggestion takes a while第一個建議要等一下

The model is loading. On a Mac that is short of memory this can take minutes; Lint waits up to 10 minutes. After 5 minutes without a suggestion the model leaves memory, and the next request loads it again in a few seconds.

模型正在載入。在記憶體吃緊的 Mac 上可能要幾分鐘，Lint 最多等 10 分鐘。5 分鐘沒有要求建議時，模型會先釋放記憶體，下次要求時幾秒內重新載入。

The download stopped下載中斷了

Choose Set Up Local AI… in the menu bar menu and download again: it continues where it stopped. A file that fails its check is deleted and never used.

在選單列選單點「設定本機 AI…」再下載一次，會從中斷處繼續。驗證失敗的檔案會被刪除，絕不會使用。

The pencil icon is not in the menu bar選單列上找不到鉛筆圖示

When the menu bar is full, macOS hides some icons. Close a few menu bar apps, check System Settings → Menu Bar on newer macOS, or look in your menu bar manager (such as Bartender or Ice). Lint's shortcuts work either way.

選單列太滿時，macOS 會隱藏部分圖示。可以關掉幾個選單列 App；在較新的 macOS 上檢查「系統設定 → 選單列」；或到你的選單列管理工具（例如 Bartender、Ice）裡找。不管圖示有沒有顯示，Lint 的快捷鍵都能用。

Not enough disk space磁碟空間不足

Before downloading, Lint checks for about 1.2 times what is still missing and tells you how much it needs and how much your Mac has.

下載前，Lint 會檢查是否有「還缺的部分 ×1.2」的空間，並告訴你需要多少、這台 Mac 有多少。
